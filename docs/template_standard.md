# Template Standard

## Global Page Requirements

Every generated page should include:

- Top/emergency bar
- Header navigation
- Large phone number where relevant
- Quote form button
- Internal links
- Footer
- Mobile sticky CTA
- Canonical URL
- Meta description
- Static HTML only

## Service Page Structure

Every service page must follow this structure:

1. Emergency/top bar
2. Header/navigation
3. Hero section
   - H1
   - short intro
   - huge phone number
   - quote form button
4. Trust bar
   - Free Estimates
   - Fast Response
   - Local Service
   - Residential Help
5. Main service copy
6. Common situations/checklist
7. Process section
   - Call
   - Estimate
   - Schedule
   - Work completed
8. Related services/internal links
9. FAQ
10. Service area/internal links
11. Final CTA
12. Footer
13. Mobile sticky call/form bar

## Homepage Structure

The homepage must include:

1. Hero with large phone number and quote CTA
2. Services overview
3. Trust bar
4. About snippet
5. Service area/location links
6. FAQ preview or trust section
7. Final CTA
8. Footer
9. Mobile sticky CTA

## Contact Page Structure

The contact page must include:

1. Large phone number
2. Quote form button
3. Email
4. Service area
5. Hours
6. CTA section
7. Footer
8. Mobile sticky CTA

## FAQ Page Structure

The FAQ page must include:

1. Hero
2. Large phone number
3. Quote form button
4. 15–25 FAQs
5. Internal links to services
6. Final CTA
7. FAQ schema when possible

## Location Page Structure

Every location page must include:

1. H1 targeting service + city
2. Local intro
3. Core service links
4. Localized content
5. FAQs
6. CTA
7. Links to nearby location pages
8. Footer

## CTAs

Each page should include CTAs in:

- Hero
- Mid-page or sidebar
- Bottom CTA
- Mobile sticky bar

Do not overload pages with excessive buttons.
