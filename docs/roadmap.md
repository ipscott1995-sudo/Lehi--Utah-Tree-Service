# Roadmap

## V1 — Static Generator

Goal: Generate complete local SEO websites locally.

Includes:

- config.json
- content.json
- generate_site.py
- homepage template
- service page template
- location page template
- about template
- contact template
- FAQ template
- sitemap.xml
- robots.txt
- mobile sticky CTA
- large hero phone number
- external quote form links

No deployment automation yet.

## V2 — Image Support

Goal: Add optimized images without slowing sites down.

Includes:

- image fields in config.json
- hero images
- service images
- WebP support
- alt text
- lazy loading
- width/height attributes
- fallback placeholders

## V3 — AI Content Workflow

Goal: Generate content.json from config.json.

Includes:

- content generator prompt
- local SEO copy standards
- service page copy generation
- FAQ generation
- location page generation
- manual edit ability

## V4 — Deployment Automation

Goal: Automate publishing.

Includes:

- GitHub repo creation
- Cloudflare Pages deployment
- custom domain setup
- sitemap submission workflow

## V5 — Lead Operations

Goal: Systematize lead capture.

Includes:

- CallRail number tracking
- form URL management
- lead tracking spreadsheet/Airtable
- call/form reporting

## V6 — Citation and Backlink Workflow

Goal: Support ranking work.

Includes:

- citation checklist
- backlink opportunity list
- referring domain tracker
- outreach templates
- citation data export

## V7 — Multi-Site Scaling

Goal: Generate many sites from CSV/Airtable.

Includes:

- batch generation
- multi-site config files
- output per domain
- reporting dashboard
