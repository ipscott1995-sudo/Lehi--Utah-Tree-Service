# Project Spec

## Goal

Build a repeatable system for generating static local lead-generation websites for rank-and-rent.

The user should be able to provide basic site details, and the system should generate a complete, fast, mobile-optimized, SEO-ready website focused on phone calls and quote form submissions.

## Primary Business Model

Rank-and-rent local lead generation.

The sites are built to rank in Google, generate calls/form leads, and later rent those leads to local service businesses.

## Required Inputs Per Site

- Business name
- Niche/service category
- City
- State
- Domain
- Phone number
- Email address
- Quote form URL
- Four core services
- Four nearby location pages

## Required Output Per Site

- Homepage
- Four service pages
- About page
- Contact page
- FAQ page
- Four location pages
- Sitemap.xml
- Robots.txt
- Static HTML/CSS/JS
- Mobile sticky call/form CTA
- Large hero phone number
- Clear quote form button

## Conversion Goals

Priority order:

1. Phone calls
2. Quote form submissions
3. Everything else

Every page should make calling or requesting a quote obvious within seconds.

## Audience

Primary audience:

- Residential homeowners
- Apartment owners
- Property owners

Secondary audience:

- Small commercial property owners

## Tone

The writing should feel:

- Local
- Professional
- Honest
- Slightly premium
- Clear and direct

Avoid exaggerated claims, fake reviews, fake awards, fake business history, or fake certifications.

## Differentiation Strategy

The sites will win through:

1. Low-competition city/niche selection
2. Strong backlinks
3. Strong referring domains
4. Fast static websites
5. Better mobile conversion than competitors

## Standard Page Structure

Every major page should follow this structure:

1. Emergency Banner
2. Header
3. Hero
4. Trust Bar
5. Page-Specific Content
6. Final CTA
7. Footer
8. Mobile Sticky CTA

This applies to:

- Homepage
- Service pages
- Location pages
- About page
- Contact page
- FAQ page

New future pages should follow this same structure unless there is a specific reason not to.

## Non-Negotiables

- Static HTML output
- Fast load times
- Mobile-first layout
- Clear phone CTA
- External quote form CTA
- No fake testimonials
- No fake ratings
- No fake founders
- No fake physical address
- No fake years in business
- No heavy frameworks
