# SEO Standard

## Technical SEO

Every generated page must include:

- Unique title tag
- Unique meta description
- One H1
- Canonical URL
- Internal links
- Clean URL
- Mobile-friendly layout
- Fast static HTML
- No unresolved placeholders
- No fake structured data

## Site Files

Every generated site must include:

- sitemap.xml
- robots.txt

## Sitemap

The sitemap must include:

- homepage
- about page
- contact page
- FAQ page
- every service page
- every location page

## Schema

Use schema only when it is accurate.

Allowed schema:

- LocalBusiness or industry-specific local business schema
- Service schema
- FAQPage schema
- BreadcrumbList schema

Do not use aggregateRating unless real review data exists.

Do not add fake reviews.

## Internal Linking

Every service page should link to:

- other service pages
- contact page
- FAQ page
- location pages when appropriate

Every location page should link to:

- main service pages
- other nearby location pages
- contact page

Homepage should link to:

- all core services
- all location pages
- contact
- FAQ

## Performance

Generated sites should be:

- static HTML
- one main CSS file
- one small JS file
- no unnecessary embeds
- no heavy frameworks
- image-ready but not image-dependent in V1

## Future Image SEO

When images are added:

- Use WebP
- Compress images
- Use descriptive file names
- Add alt text
- Set width and height
- Lazy load non-critical images
