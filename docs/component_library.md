# Component Library

## Purpose

This document defines the reusable UI components used throughout every generated website.

These are conceptual components only.

They are NOT separate HTML partials.

Each page template implements these components directly in HTML.

Every improvement to a component should eventually be reflected across all page templates.

---

# Component Rules

Every component should satisfy at least one objective:

• Improve rankings

• Increase conversions

• Increase trust

• Improve navigation

If a component does none of those things, it should not exist.

---

# Design Philosophy

The websites should resemble established, premium local contractors—not generic SEO landing pages.

Design principles:

- clean
- modern
- trustworthy
- uncluttered
- fast
- mobile-first
- easy to scan

The user should immediately think:

"This looks like a legitimate local business."

---

# Reusability

Every component should work across nearly every local service niche, including but not limited to:

- Tree Service
- Roofing
- Plumbing
- HVAC
- Concrete
- Drywall
- Junk Removal
- Remodeling
- Electrical
- Pest Control
- Landscaping
- Painting

Avoid niche-specific assumptions inside components whenever possible.
